# 马卡龙列表高度与对齐修复

2026-10-17；分支 `fix/macaron-list-density`，原目录开发，未使用 worktree。

用户截图中的时间被皮肤规则挪成独立一行，项目/机器又位于第三行。时间缩进 24px，项目文字却从图标左侧开始，造成三行过高与文字错位。

六套马卡龙列表改为两行：第一行保留 Agent 图标、标题、分享与状态标记；第二行左侧放项目/机器，右侧放任务进度与时间。项目文字与标题起点对齐，缩进使用 `1.5rem` 跟随图标和字号缩放。缩小上下内边距和条目间距，不设置固定高度，长标题与长路径仍可省略并保留原始文本。默认、森林、折叠侧栏与会话引用预览不应用这套列表规则。

真实组件、合成数据的 390×844 Chromium 对照中，五类带项目说明的条目从 81px 降为 54px。[前后对比](screenshots/macaron-list-density/comparison.png)。该数据是组件测量，非实机 Safari 测量。
